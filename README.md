# ERP CRM Suchir

A mini ERP + CRM operations portal for the full-stack developer case study.

## Stack
- Backend: Node.js, TypeScript, Express, Prisma, PostgreSQL
- Frontend: React, TypeScript, Vite
- Auth: JWT + bcrypt

## Modules
- Authentication and RBAC
- Customer CRM
- Products and inventory
- Stock movement log
- Sales challans

## Development
See `backend/.env.example` and `frontend/.env.example`.

This implementation is inspired by common ERP/CRM patterns, but is purpose-built for the supplied case study rather than a copy of another repository.
